# ETHOS introduction films

Rebuild the ETHOS introduction films, a Chinese and an English edition, from tracked sources with [filmkit](https://github.com/HengYangDS/filmkit).

Each film explains [ETHOS](https://github.com/HengYangDS/ethos) as its documents state it at the commit that `content/source-manifest.json` pins. Each edition lasts exactly 900 seconds at 60 fps, with 48 kHz stereo narration in one synthetic voice, small single-line captions and no music. The films are in production, and no release has been published yet.

Author: Yang HENG.
